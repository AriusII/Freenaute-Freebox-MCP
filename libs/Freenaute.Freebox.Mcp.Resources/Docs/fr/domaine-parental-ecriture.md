# Domaine écriture du contrôle parental

Les outils disponibles exposent la configuration et les filtres, mais aucune surface d'écriture Freebox MCP ne
permet aujourd'hui de modifier une règle, un planning ou une politique d'appareil.

## Outils actuels

- `freebox_parental_config`
- `freebox_parental_filters`

Les identifiants sont hachés. Adresses MAC, noms d'hôtes, adresses IP, descriptions et cibles brutes sont exclus.
`freebox://live/parental-write` est une ressource live, jamais une commande de mutation.
